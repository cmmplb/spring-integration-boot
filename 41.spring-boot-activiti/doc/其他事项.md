# 其他事项：

如果没有使用 undertow 容器，使用 tomcat debug 模式下启动项目，控制会打印这个异常：

````
javax.management.InstanceNotFoundException: org.springframework.boot:type=Admin,name=SpringApplication
````

这些报错没啥影响，我的 idea 版本是 2023.3.2，网上的解决办法：

1. 找到工具栏，选择 Edit Configurations...

![Edit Configurations.png](.%2Fimage%2FEdit%20Configurations.png)

2. 选择 Modify Options

![Modify Options.png](.%2Fimage%2FModify%20Options.png)

3. 勾选 Disable launch optimization 和 Disable JMX endpoints

![Disable.png](.%2Fimage%2FDisable.png)
